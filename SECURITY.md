# Politique de sécurité

## Versions concernées

Aucune matrice de versions prises en charge n'est actuellement publiée. En attendant que les mainteneurs en définissent une, les signalements concernant la branche principale et la dernière version publiée sont les plus utiles; cela ne constitue pas une garantie de support des anciennes versions.

## Signaler une vulnérabilité

Veuillez utiliser le bouton **Report a vulnerability** de l'onglet **Security** du dépôt pour envoyer un signalement privé :

https://github.com/Ulrich506/projet-github-simplifier/security/advisories/new

Le signalement privé doit être activé dans les paramètres du dépôt pour que ce canal soit disponible. Si le bouton n'est pas accessible, ne publiez pas les détails dans une issue publique; contactez le propriétaire du dépôt par son profil GitHub afin de convenir d'un canal privé. Les mainteneurs doivent vérifier et activer le signalement privé avant de présenter cette politique comme un canal opérationnel.

## Informations utiles

Incluez, si possible :

- les versions de l'application, du système d'exploitation et les prérequis concernés ;
- les étapes minimales pour reproduire le problème dans un environnement de test ;
- l'impact observé et les privilèges nécessaires ;
- les journaux expurgés de jetons, mots de passe, données privées et contenu sensible ;
- une proposition de correction, si vous en avez une.

N'envoyez pas de jeton GitHub actif, de clé privée ni de données personnelles réelles.

## Traitement des signalements

Les mainteneurs examineront les signalements selon leurs disponibilités. Aucun délai de réponse ou de correction n'est garanti. Merci de ne pas publier les détails avant d'avoir convenu d'une divulgation avec les mainteneurs.
